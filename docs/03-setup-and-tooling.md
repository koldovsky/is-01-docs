# Setup and Tooling

## Prerequisites

| Tool | Minimum Version | How to Install |
| --- | --- | --- |
| Node.js | 18.0.0 | https://nodejs.org/ |
| Yarn | 1.22.22 | `npm install -g yarn` or `corepack enable` |
| Git | latest stable | https://git-scm.com/ |
| Docker | latest stable | https://docs.docker.com/get-docker/ |

## Getting the Code

1. Clone the repository:

```bash
git clone https://github.com/excalidraw/excalidraw.git
cd excalidraw
```

2. Confirm you are on `main`:

```bash
git checkout main
```

3. Install dependencies:

```bash
yarn install
```

## Environment Configuration

This repo does not include a committed `.env` file in source control. The app uses Vite environment variables and local development defaults.

Create a local `.env` file in the repo root if needed.

```bash
# .env
VITE_APP_DISABLE_SENTRY=false # disable Sentry in local dev when set to true
VITE_APP_GIT_SHA=local-dev # commit hash injected during build
VITE_APP_ENABLE_TRACKING=false # enable analytics/tracking in local dev
```

> 💡 **Tip:** Use `VITE_` prefixed variables for Vite and keep secrets out of source control.

## Installing Dependencies

```bash
yarn install
```

If you want a clean install:

```bash
yarn clean-install
```

## Running the App Locally

1. Start the app from the monorepo root:

```bash
yarn start
```

2. Open the browser at the URL shown in the terminal, typically `http://localhost:5173`.

3. To run a production-style preview:

```bash
yarn build:preview
```

4. To start the app in production mode locally:

```bash
yarn start:production
```

### Supporting Services

The app is primarily browser-based and does not require a local backend service in this repo.

> ⚠️ **Warning:** The `docker-compose.yml` file is available for container-based local development, but it mounts the repo into a container and is not required for normal workflow.

## Running Tests

| Scope | Command |
| --- | --- |
| Full test suite | `yarn test:all` |
| App tests | `yarn test:app` |
| Lint and formatting | `yarn test:code` and `yarn test:other` |
| Typecheck | `yarn test:typecheck` |
| Coverage | `yarn test:coverage` |

Run a single test file:

```bash
yarn test:app path/to/file.test.ts
```

Run tests by pattern:

```bash
yarn test:app -- --testNamePattern="pattern"
```

Coverage reports are generated by Vitest, typically in the `coverage/` directory.

## Useful Dev Scripts

| Command | What It Does |
| --- | --- |
| `yarn start` | Start the local development app. |
| `yarn build` | Build the production app. |
| `yarn build:packages` | Build all package libraries. |
| `yarn build:preview` | Build and preview the app locally. |
| `yarn test:all` | Run CI-like test commands. |

| `yarn release` | Run the release script for package publishing. |

## Common Setup Problems

- **Problem:** Node version is too old.
  **Fix:** Install Node >= 18 and verify with `node --version`.

- **Problem:** `yarn install` fails due to missing `node_modules` or cache issues.
  **Fix:** Run `yarn clean-install` or remove `node_modules` and retry.

- **Problem:** Local app does not start on port 5173.
  **Fix:** Check if another process is using the port or update Vite port config.

- **Problem:** `yarn test:code` reports lint or formatting errors.
  **Fix:** Run `yarn fix` and re-run tests.

- **Problem:** TypeScript typecheck fails after editing packages.
  **Fix:** Run `yarn test:typecheck` and fix errors in the affected package or shared type definitions.

- **Problem:** Docker container startup does not reflect local changes.
  **Fix:** Use direct `yarn start` for development or rebuild the container after code changes.
