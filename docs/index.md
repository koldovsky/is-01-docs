# Excalidraw Onboarding Docs

This documentation suite helps a new engineer understand the Excalidraw monorepo, the app and package architecture, developer tooling, and team workflows. It is designed as a practical starting point for setup, contribution, and delivery in this repository.

| File | Description |
| --- | --- |
| `01-project-overview.md` | High-level project context, goals, stakeholders, and first-week priorities. |
| `02-architecture.md` | System architecture, component breakdown, tech stack, and design decisions. |
| `03-setup-and-tooling.md` | Local setup, environment configuration, install commands, and test tooling. |
| `04-workflows.md` | Branching strategy, change process, code review, CI/CD, deployments, and incident response. |

## Recommended reading order

1. `01-project-overview.md`
2. `02-architecture.md`
3. `03-setup-and-tooling.md`
4. `04-workflows.md`

> 💡 **Diagrams are embedded in `02-architecture.md` and `04-workflows.md` so you can view them alongside the related documentation.**
